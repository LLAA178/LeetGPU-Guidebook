### [multi-agent-simulation](https://leetgpu.com/challenges/multi-agent-simulation)
*环境: CUDA*

给定长度为 `4N` 的智能体状态数组 `agents`（第 `i` 个智能体占连续 4 个单精度浮点数 `[x_i, y_i, vx_i, vy_i]`，分别表示二维位置与速度），对每个智能体 `i` 找出所有满足欧氏距离严格小于半径 `r = 5.0`（即 `(x_i - x_j)^2 + (y_i - y_j)^2 < 25.0`）的其他智能体 `j != i`：若有邻居则求邻居平均速度 `v_avg` 并更新 `v_new = v_i + 0.05 * (v_avg - v_i)`（无邻居时保持 `v_new = v_i`），再更新位置 `p_new = p_i + v_new`，将 `[px_new, py_new, vx_new, vy_new]` 写入 `agents_next`。

用两个不同间距的智能体例子对比看清临界判定与更新步骤：
1. **恰好落在半径边界（不交互）**：`Agent 0 = [0, 0, 1, 0]`、`Agent 1 = [3, 4, 0, -1]`，两者距离平方为 `3^2 + 4^2 = 25.0`，由于规则要求**严格小于** `25.0`，双方邻居集合均为空，速度保持不变，位置各自推进一步变为 `[1, 0, 1, 0]` 与 `[3, 3, 0, -1]`。
2. **落在半径以内（相互对齐）**：若 `Agent 1` 位于 `[1, 1, 0, 1]`，距离平方为 `2.0 < 25.0`，则 `Agent 0` 的邻居均速为 `[0, 1]`，新速度为 `[1, 0] + 0.05 * ([-1, 1]) = [0.95, 0.05]`，新位置为 `[0.95, 0.05]`。

> baseline

基线版让每个线程负责一个智能体 `i`，顺序遍历全部 `j = 0 .. N - 1`（跳过自身），用严格单精度最近舍入原语计算距离平方，把所有满足 `dist_sq < 25.0` 的邻居速度累加到双精度变量中求均值并写回新状态：

```cuda
// 逐个检查全部 N 个智能体，双精度累加半径内邻居速度消除顺序舍入误差
for (int j = 0; j < N; ++j) {
    if (j == i) continue;
    if (exact_dist2d_sq(px, py, agents[j * 4], agents[j * 4 + 1]) < 25.0f) {
        sum_vx += static_cast<double>(agents[j * 4 + 2]);
        sum_vy += static_cast<double>(agents[j * 4 + 3]);
        ++cnt;
    }
}
```

> optimized：小规模共享内存分块 + 2 的幂次精确步长二维空间网格与去重空间哈希

看官方计时规模 `N = 10,000`（坐标均匀分布在 `[-1000, 1000] × [-1000, 1000]`，上限可达 `N = 100,000`）：
- 全量两两检查要做 **1 亿次**距离计算（`N = 100,000` 时达 **100 亿次**）；而交互半径固定为 `r = 5.0`，圆面积仅占整个 `2000 × 2000` 场地的 **五万分之一**，平均每个智能体周围其实不到 `1` 个真实邻居，99.99% 的远距离配对全在做无用功。

优化版按规模与空间跨度自适应构建零漏检局部邻域结构：
- **`N < 512` 单核共享内存合并分块**：小群体只启动 1 个核函数，块内 128 个线程以步长 1 合并加载连续 `512` 个浮点数进入片上共享内存（shared memory），全块广播复用。
- **`N >= 512` 精确 2 的幂次网格宽度（`H = 8.0` 或 `16.0`）二维分桶与空间重排**：
  1. **零尾数舍入分桶保证 `3 × 3` 邻域 100% 完备**：首趟归约出点集包围盒并顺手清零桶计数。选取严格大于交互半径 `5.0` 的 **2 的幂次格子边长** `H = 16.0`（倒数 `0.0625 = 2^{-4}`）或 `H = 8.0`（倒数 `0.125 = 2^{-3}`）：在 IEEE-754 浮点数中乘 `2` 的整数次幂只改指数位、尾数零舍入，且留有至少 `3.0` 的安全裕量，从数学上严格保证任何距离小于 `5.0` 的点对必定落在自身及周围紧邻的 **`3 × 3 = 9` 个格子**之内，绝无跨格漏检。
  2. **二维直连网格与去重空间哈希双模式**：当包围盒格子数不超过 `128 × 128`（`N <= 25,000`，如官方计时场景生成 `127 × 127 = 16,129` 格，计数表仅 `63 KB` 全驻留缓存）或 `256 × 256` 时，直接按二维坐标无碰撞编码；若遇到超大稀疏坐标范围，则自动切入空间哈希并在查询 `3 × 3` 邻格时做桶号去重，严防哈希碰撞引发重复计数。
  3. **`float4` 空间聚集重排与双精度速度归约**：经单块前缀和算出各桶起始偏移后，用 `float4`（单条 128 位指令读写 4 个连续 `float`）把智能体按格子顺序连续重排进二级缓存（L2 cache）。模拟核函数按重排顺序分配线程，使同一线程束（warp）的 32 个线程读取同一片局部 `3 × 3` 邻格缓存，平均每个智能体只需检查寥寥数个候选点即可完成精确双精度速度归约：

```cuda
// 仅扫描自身所在的 3x3 邻近二维格子，候选点数从 10,000 骤降至个位数
for (int ny = y_lo; ny <= y_hi; ++ny) {
    for (int nx = x_lo; nx <= x_hi; ++nx) {
        const int b = ny * gw + nx;
        for (int k = g_bucket_starts[b]; k < g_bucket_starts[b + 1]; ++k) {
            if (k != s && exact_dist2d_sq(me.x, me.y, nb.x, nb.y) < 25.0f) { ... }
        }
    }
}
```

若遇到大量智能体挤在极小区域内的极端退化输入，前缀和核函数在设备端自动置位回退标志，零主机同步无缝切回共享内存分块全对扫描。

在官方性能测试规模 `N = 10,000` 下（每次计时前刷空 L2 缓存，取 15 轮中位数）：全局扫描基线耗时 `1.37 ms`，二维空间网格重排优化版降至 **`0.049 ms`**（提速 **`27.82x`**）；在 LeetGPU 官方 T4 评测中一次通过全部测试，耗时 **0.07 ms**（第 **96.8** 百分位）。
