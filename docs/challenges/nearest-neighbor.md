### [nearest-neighbor](https://leetgpu.com/challenges/nearest-neighbor)
*环境: CUDA*

给定长度为 `3N` 的三维点坐标数组 `points`（每 3 个连续浮点数表示一个点 `(x_i, y_i, z_i)`），为每个点 `i` 找出除自身以外欧氏距离平方 `(x_i - x_j)^2 + (y_i - y_j)^2 + (z_i - z_j)^2` 最小的点下标 `j != i`（距离完全相同时取最小下标 `j`），写入 `indices[i]`。

用官方三点例子 `points = [(0, 0, 0), (1, 0, 0), (5, 5, 5)]` 走一遍：
1. **逐点求异点距离平方**：第 0 号点到第 1、2 号点的距离平方分别为 `1^2 + 0 + 0 = 1` 和 `5^2 + 5^2 + 5^2 = 75`，最近邻是 `1`；第 1 号点到第 0、2 号点的距离平方分别为 `1` 和 `4^2 + 5^2 + 5^2 = 66`，最近邻是 `0`；第 2 号点到第 0、1 号点的距离平方分别为 `75` 和 `66`，最近邻是 `1`。
2. **输出下标**：最终得到 `indices = [1, 0, 1]`。注意由于评测要求下标逐个精确相等（零误差容忍），距离平方必须直接按差值平方和计算，避免展开成 `||p_i||^2 + ||p_j||^2 - 2 p_i · p_j` 在相近点上产生大数相消误差。

> baseline

基线版让每个线程独立负责一个查询点 `i`，顺序扫描全部 `j = 0 .. N - 1`（跳过 `j == i`），用严格单精度最近舍入原语算出精确距离平方并维护最小距离与最小下标：

```cuda
// 逐个扫描全部 N 个点，严格按差值平方和求距离平方并保留首个最小距离下标
for (int j = 0; j < N; ++j) {
    if (j == i) continue;
    const float d2 = exact_dist_sq(xi, yi, zi, points[j * 3], points[j * 3 + 1], points[j * 3 + 2]);
    if (d2 < best_d2) {
        best_d2 = d2;
        best_j = j;
    }
}
indices[i] = best_j;
```

> optimized：小规模共享内存合并分块 + 大规模向负无穷舍入精确剪枝三维均匀网格

看官方计时规模 `N = 10,000`（上限可达 `N = 100,000`）：暴力两两比较要做 **1 亿次**三维距离计算（`N = 100,000` 时更是暴涨到 **100 亿次**）；而在三维空间中，一个点的最近邻几乎总落在它紧邻的局部体素（voxel，三维空间划分出的小立方体格）内。难点在于怎样既砍掉 99% 以上的远距离点对，又在浮点数边界舍入和等距并列下标规则下做到 **100% 数学精确零漏检**。

优化版按点数规模自适应切换两套精确路径：
- **`N < 2,048` 单核共享内存合并分块**：小点云下建表开销高于直接计算，只启动 1 个核函数。块内 128 个线程以步长 1 合并加载连续 `384` 个浮点数进入片上共享内存（shared memory），再由全块线程通过无冲突的共享内存广播复用同一批候选点。
- **`N >= 2,048` 精确壳层下界剪枝三维体素网格（`16^3 = 4,096` 或 `32^3 = 32,768` 格）**：
  1. **二分切分面消除分桶边界歧义**：先归约出点云三维包围盒并生成单调递增切分面 `split_{x,y,z}[0..G]`，每个点通过 4~5 步二分比较 `coord >= split[m]` 确定所属格子，从序关系上严格保证格 `c` 内所有点满足 `split[c] <= coord < split[c + 1]`，彻底杜绝乘加分桶在边界处的 1 ULP 越格误差；随后对格子计数做单块前缀和，将点重排为空间连续的结构体数组（SoA，把 `x`、`y`、`z` 各自连续存放）。
  2. **空间重排查询 + IEEE 向负无穷定向舍入（Round-Down）精确剪枝**：按体素顺序分配线程，使同一个线程束（warp）的 32 个线程查询空间紧邻的点、共享同一片一级缓存（L1 cache）中的邻居体素。从自身所在格 `r = 0` 向外逐层扩展切比雪夫壳层 `r = 1, 2, ...`，用向负无穷舍入指令 `__fsub_rd`、`__fmul_rd`、`__fadd_rd` 算出外部半空间与单个体素包围盒的距离平方严格下界 `cell_d2`；仅当 `best_d2 < cell_d2`（严格小于，连等距更小下标并列点也绝不误剪）时才跳过，平均每个点只需检查几十个近邻点即可提前终止：

```cuda
// 用向负无穷定向舍入指令算出体素包围盒的严格距离平方下界，严格小于时才安全跳过
const float cell_d2 = __fadd_rd(dyz2_cell, axis_cell_d2_rd(px, ix, s_sx, G));
if (best_d2 < cell_d2) {
    continue;
}
```

若遇到极端退化输入（如大量点完全重合挤进同一个体素），前缀和核函数在设备端自动置位退化标志，搜索核函数零主机同步无缝切换回共享内存分块扫描兜底。

本地 Tesla T4（CUDA 12.4）每次计时前刷空 L2 缓存，在官方计时规模 `N = 10,000` 下取 15 轮中位数：暴力扫描基线耗时 `0.819 ms`，三维体素精确剪枝版降至 **`0.065 ms`**（提速 **`12.60x`**）；在 LeetGPU 官方 T4 评测中一次通过全部测试，耗时 **0.09 ms**（第 **99.7** 百分位）。
