### [muon-optimizer](https://leetgpu.com/challenges/muon-optimizer)
*环境: CUDA*

给定形状为 `[M, N]` 的当前梯度矩阵 `G`、动量缓冲区 `Buf` 与动量系数 `momentum`，计算 Muon 优化器的单步正交化更新方向：先合成 `V = momentum * Buf + G` 并按弗罗贝尼乌斯范数（Frobenius norm，全部元素平方和开根号）归一化为 `X_0 = V / (||V||_F + 1e-7)`（当 `M > N` 时先转置使格拉姆矩阵总落在较短维），接着以五次多项式系数 `(a, b, c) = (3.4445, -4.7750, 2.0315)` 迭代 5 轮 Newton-Schulz 更新 `A = X X^T`、`B = b A + c A^2`、`X = a X + B X`，最后乘上 `sqrt(max(M, N))`（若曾转置则转置回原形状）写入 `output`。

用官方例子 `M = 2, N = 3, momentum = 0.9` 走一遍：
1. **动量合并与范数归一化**：`V = 0.9 * Buf + G = [[0.59, -0.82, 2.0], [0.73, 0.36, -0.41]]`，平方和开根号得 `||V||_F ≈ 2.41897`，除以 `||V||_F + 1e-7` 后使最大奇异值不超过 `1`。
2. **五轮奇异值拉平与尺度还原**：由于 `2 <= 3` 无需转置，每轮先算 `2 × 2` 对称格拉姆矩阵 `A = X X^T` 与 `B = b A + c A^2`，再左乘更新 `2 × 3` 的 `X = a X + B X`，把不同强度的奇异方向同时推向 `1` 附近；5 轮结束后乘以 `sqrt(3) ≈ 1.73205`，得到 `[[0.5427371, -0.4092258, 1.1156158], [1.7146817, 0.5666907, -0.3777507]]`。

> baseline

基线版先用两趟双精度归约求出 `||V||_F` 并完成归一化（以及 `M > N` 时的前置转置），随后在 5 轮循环里依次启动 3 个标准的 `16 × 16` 共享内存分块单精度矩阵乘法核函数，分别计算完整的 `A = X X^T`、`B = b A + c A^2` 与 `X = a X + B X`，最后缩放写回 `output`：

```cuda
// 5 轮 Newton-Schulz 迭代，每轮依次执行 3 次完整的分块单精度矩阵乘法
for (int step = 0; step < 5; ++step) {
    baseline_gram_kernel<<<grid_rr, block2d>>>(R, C, step & 1);
    baseline_polyB_kernel<<<grid_rr, block2d>>>(R);
    baseline_updateX_kernel<<<grid_rc, block2d>>>(R, C, step & 1);
}
```

> optimized：对称上三角剪枝镜像 + 指数预条件三次残差拆分 Tensor Core + 末步融合

看官方计时规模 `M = 1,024, N = 1,024`：5 轮迭代共包含 **15 次 `1024 × 1024` 矩阵乘法（总计 `32.21 GFLOP`）**，且整份 `4 MiB` 工作矩阵刚好能驻留在 Tesla T4 的 `4 MiB` 二级缓存（L2 cache）中，瓶颈完全集中在矩阵乘算力与精度控制上：
- **利用对称性砍掉近一半矩阵乘块**：每轮前两步 `A = X X^T` 和 `B = b A + c A^2` 生成的都是严格的对称矩阵。优化版仅对上三角分块 `bm <= bn` 启动线程块（`1024 × 1024` 下 `64 × 64` 分块从 `256` 个压减到 `136` 个，直接省去 10 次矩阵乘中近一半的乘加工作量）；每个上三角块算完后借用共享内存同时向 `(bm, bn)` 与镜像位置 `(bn, bm)` 合并写出，兼顾无分歧访存与逐比特对称性；且正因 `A = A^T`，第二步 `A @ A` 天然等价于行连续的 `A @ A^T`，省掉额外的共享内存转置。
- **指数预条件双半精度残差拆分（Scaled 3-MMA Split）攻克次正规数精度丢失**：直接用半精度（FP16）跑张量核心（Tensor Core，GPU 上加速矩阵乘加的专用硬件）无法满足 `1e-4` 容差；更隐蔽的是，归一化后的 `1024 × 1024` 矩阵元素幅值在 `1e-3` 附近，若直接拆分残差 `x - float(half(x))`，残差幅值约 `5e-7`，会跌入 FP16 次正规数区间（`< 6.1e-5`）丢失大量有效位。由于数学上可严格证明全流程任意中间元素幅值恒小于 `3.0`，优化版在送入共享内存前先乘精确的 2 的幂次 `2^8 = 256` 把主部托举到正规区间（峰值 `< 768`，远低于 FP16 上限 `65504`），再将残差乘上 `2^11 = 2048` 存入半精度对 `(hi, lo)`，分别累加到高低两个单精度寄存器桶并在末尾乘回精确的 `2^-16` 与 `2^-27`，15 次链式矩阵乘后的最大误差在 `1024 × 1024` 规模下仅约 `9.75e-5`（严格低于 `1e-4` 容差）：

```cuda
// 先乘 2^8 避开 FP16 次正规数下溢，再将残差放大 2^11 拆成双半精度对送入 3-MMA Tensor Core
const float s0 = x0 * 256.0f, s1 = x1 * 256.0f;
const half2 hi = __floats2half2_rn(s0, s1);
const float2 hi_f = __half22float2(hi);
const half2 lo = __floats2half2_rn((s0 - hi_f.x) * 2048.0f, (s1 - hi_f.y) * 2048.0f);
```

- **单趟范数预取与末步尾部融合**：首趟用 `float4`（单条 128 位指令读取 4 个连续 `float`）合并读入 `G` 与 `Buf` 算出 `V` 缓存在 L2 中，同时用无锁末尾块归约算出双精度 `||V||_F`，避免二次读取输入；第 5 轮的 `a X + B X` 在核函数尾部直接乘上 `sqrt(max(M, N))`（并在 `M > N` 时于片上完成合并转置）一步写回 `output`。极小尺寸自动走同样带对称剪枝的纯单精度寄存器分块路径。

本地 Tesla T4（CUDA 12.4）每次计时前刷空 L2 缓存，在官方计时规模 `M = 1,024, N = 1,024, momentum = 0.9` 下取 15 轮中位数：分块单精度基线耗时 `51.75 ms`，对称剪枝 Tensor Core 优化版降至 **`4.61 ms`**（提速 **`11.23x`**，折算标称算力达 `6.99 TFLOPS`）。
